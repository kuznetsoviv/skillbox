### Описание {#description}

Разработан телеграм бот для поиска фильмов/сериалов.
Телеграм бот поддерживает следующие команды:
* **/start** - приветствие пользователя
* **/help** - показать список всех команд
* **/movie_search** - выполнить поиск фильмов/сериалов по нименованию
* **/movie_by_rating** - выполнить поиск фильмов/сериалов по рейтингу
* **/low_budget_movie**[^low_budget_movie] - выполнить поиск фильмов/сериалов с низким бюджетом
* **/high_budget_movie**[^high_budget_movie] - выполнить поиск фильмов/сериалов с высоким бюджетом
* **/history** - показать историю запросов на дату

### Требования {#requiments}

Для работы телеграм бота необходимо:

1. python
2. telegram
3. token для подключения телеграм бота
4. [api key](https://api.kinopoisk.dev) для выполнения запросов поиска фильмов 

### Запуск {#run}

1. склонировать репозиторий и зайти в корневую папку
2. создать файл .env и заполнить значения BOT_TOKEN и RAPID_API_KEY
2. выполнить команду ```pip install -r requirements.txt```
3. выполнить команду `python main.py`

### Примечания {#remarks}

* после запуска приложения будет создан файл search_history.db - база данных для хранения истории поиска

[^low_budget_movie]: Бюджет фильма меньше, чем 5 000 000 $.
[^high_budget_movie]: Бюджет фильма больше, чем 50 000 000 $.
